## MODO DEL DIRECTORIO ##
 ---
   # OBTEJTIVO #
	- Los archivos de configuración general de las librerías deben ubicarse en la raíz del
 	proyecto para garantizar una estructura estandár y facilitar su detección por parte
	de las herramientas de compilación, integración y despliegue.
 --- 
  # Razones #
 	Durante la preparacion de este repositorio, el directorio raíz contenia archivos
 	temporales, pruebas y otros directorios no relacionados con la version que se 
 	deseaba compartir. Incluir dichos elementos u archivos habría incrementado innecesariamente
 	la carga de almacenamiento y el historial de cambios en GitHub.
 	Adicionalmente, parte del desarrollo se realizó utilizando un directorio paralelo, lo que generó redundancia en algunos recursos y configuraciones. Para evitar publicar contenido irrelevante o duplicado, se optó por distribuir únicamente los componentes esenciales del proyecto.
 ---
 # Proceso #
 	Por las razónes previas, la estructura publicaba inicia desde el directorio src.Los archivos
 	de configuración fueron colocados temporalmente en este directorio con el fin de
 	mantener un repositorio limpio y enfocado en los elementos necesarios para la ejecución
 	del proyecto.
 	Por lo que, en una integracion definitiva. Se recomienda trasladar dichos archivos al
 	directorio raíz del proyecto y consolidar la estructura de directorios para eliminar
 	duplicidades y alinearse con las convensiones habituales de desarrollo.
